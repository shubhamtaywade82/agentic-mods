# observability-verifier

Checks the health endpoints configured in .agentic-mods/observability.json after a change, and publishes the observability gate. It makes GET requests only, through the host's network policy.

## Commands

- `/observe`

## Shared state

Publishes `gate` for other mods and the engineering cockpit.

## Configuration

Reads `.agentic-mods/config.json` when relevant. Invalid fields are reported by `/agentic doctor` and replaced by defaults. See the repository README for the schema.

## Install

```
/plugin install observability-verifier --marketplace shubhamtaywade82/agentic-mods
```

Mods run with your permissions and are not sandboxed. Read what this one calls with `claude plugin validate mods/observability-verifier` before loading it.
