# release-conductor

Assembles release readiness from the evidence, review, architecture, migration, dependency and performance states, plus a changelog, a rollback note and the deployment assets the repository lists. Checks only: it never deploys, and writes the checklist to .agentic-mods/release/checklist.md. The changelog counts when CHANGELOG.md changed in the working tree or since the last tag.

## Commands

- `/release-gate`

## Shared state

Publishes `gate` for other mods and the engineering cockpit.

## Configuration

Reads `.agentic-mods/config.json` when relevant. Invalid fields are reported by `/agentic doctor` and replaced by defaults. See the repository README for the schema.

## Install

```
/plugin install release-conductor --marketplace shubhamtaywade82/agentic-mods
```

Mods run with your permissions and are not sandboxed. Read what this one calls with `claude plugin validate mods/release-conductor` before loading it.
