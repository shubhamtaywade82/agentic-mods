# session-meter

Shows context fill, session cost and rate-limit windows above the prompt, and warns when a threshold is crossed.

## Hooks

`session.measure`, `ui.render`.

## Install

```
/plugin install session-meter --marketplace shubhamtaywade82/agentic-mods
```

Mods run with your permissions and are not sandboxed. Read what a mod calls with `claude plugin validate mods/session-meter` before loading it. Settings, where a mod has any, are in `.agentic-mods/config.json`; see the root README.
