# response-modes

Adds a concise or plain-language response style to the system prompt, switched with /tldr, /mode-simple and /mode-off.

## Hooks

`command.run`, `prompt.compose`, `session.start`.

## Install

```
/plugin install response-modes --marketplace shubhamtaywade82/agentic-mods
```

Mods run with your permissions and are not sandboxed. Read what a mod calls with `claude plugin validate mods/response-modes` before loading it. Settings, where a mod has any, are in `.agentic-mods/config.json`; see the root README.
