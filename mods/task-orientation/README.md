# task-orientation

Keeps the goal, current task, blocker and next step visible in a pane, captured from the first prompt and set with commands.

## Hooks

`command.run`, `prompt.submit`, `session.start`, `ui.render`.

## Install

```
/plugin install task-orientation --marketplace shubhamtaywade82/agentic-mods
```

Mods run with your permissions and are not sandboxed. Read what a mod calls with `claude plugin validate mods/task-orientation` before loading it. Settings, where a mod has any, are in `.agentic-mods/config.json`; see the root README.
