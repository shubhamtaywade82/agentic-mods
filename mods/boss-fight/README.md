# boss-fight

Shows the test check as a boss battle above the prompt: the boss stands while the test check fails and falls when it passes. It reads evidence-gate's published state and changes nothing.

## Hooks

`ui.render`.

## Depends on

`evidence-gate`

## Install

```
/plugin install boss-fight --marketplace shubhamtaywade82/agentic-mods
```

Mods run with your permissions and are not sandboxed. Read what a mod calls with `claude plugin validate mods/boss-fight` before loading it. Settings, where a mod has any, are in `.agentic-mods/config.json`; see the root README.
